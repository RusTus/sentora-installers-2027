# Security Policy

Security problems in these installer files or in the panel are handled in the core repository.

Please **don't open a public issue**. [Open a private report](https://github.com/RusTus/sentora-core-2027/security/advisories/new) instead, and see the [core repository's security policy](https://github.com/RusTus/sentora-core-2027/blob/master2027/SECURITY.md) for what to include.
